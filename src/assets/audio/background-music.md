
# Musique de fond

Pour utiliser votre propre musique de fond, vous devez:

1. Préparer votre fichier audio au format MP3 (idéalement)
2. Le placer dans ce dossier (`src/assets/audio/`)
3. Renommer le fichier en `background-music.mp3` ou mettre à jour la référence dans `App.tsx`

Pour des raisons de copyright, aucun fichier audio par défaut n'est inclus.
Vous pouvez utiliser:
- Une musique que vous possédez
- Une musique libre de droits (comme celles de Bensound, Pixabay, etc.)

Formats recommandés: MP3 ou OGG, optimisés pour le web (128kbps est souvent suffisant).
